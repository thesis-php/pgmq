# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.2] 2025-12-18

### Added

* Implement batch visibility timeout.

### Changed
* More specific type for postgres transaction

### Added

* All extension [functions](https://github.com/pgmq/pgmq/blob/main/docs/api/sql/functions.md) have been implemented.
